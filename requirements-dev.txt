# Dependances directes du suivi de prix, en versions EXACTES.
#
# Pourquoi "==" et non ">=" : un minimum laisse pip installer n'importe quelle
# version future. Une mise a jour de beautifulsoup4 ou de requests peut casser
# l'extraction en silence -- et sur GitHub Actions, l'environnement est
# reconstruit a chaque execution, donc le jour ou ca casse est imprevisible.
# Avec des versions figees, le comportement d'aujourd'hui est celui de demain.
#
# Pour mettre a jour : changer une version ici, lancer `pytest` (le filet de
# securite doit rester vert), puis regenerer requirements.lock :
#     pip install -r requirements.txt && pip freeze > requirements.lock
#
# `sqlite3` n'apparait pas : il fait partie de la bibliotheque standard.

requests==2.33.1
beautifulsoup4==4.15.0
