Vérificateur de liens Power BI

Un lien par ligne, tel qu'il est enregistré dans l'annuaire. Ouvrez-le — il s'affiche dans votre navigateur, avec votre session — puis dites si c'est bien le graphique attendu. Si ce n'est pas le bon, collez le lien corrigé : la page vous rendra la liste complète à reporter dans l'annuaire.

Vos réponses restent dans ce navigateur. La page n'envoie rien : elle ne fait qu'ouvrir vos liens dans un onglet.
