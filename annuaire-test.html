1. Créer un KPI

Cliquez sur le bouton + en bas à droite (ou Nouveau KPI dans le menu). La fenêtre de création s'ouvre.

2. Décrire le KPI

Renseignez l'intitulé (obligatoire), le type, le processus et une description. Ces informations sont communes à toutes les temporalités.

Mensuelle Hebdo Quotidienne

3. Remplir les temporalités

Chaque temporalité (Mensuelle, Hebdo, Quotidienne) a ses propres liens de rapport et son rituel. Changez d'onglet pour basculer : les liens affichés suivent la temporalité.

💾 Enregistrer✓

4. Enregistrer en une fois

Un seul clic sur Enregistrer crée ou met à jour toutes les temporalités du KPI. Elles sont regroupées sur une même carte.

✏️

5. Modifier un KPI

Sur n'importe quelle carte, cliquez sur le crayon ✏️. Vous retrouvez tous les champs et toutes les temporalités, prêts à être modifiés. Décochez une temporalité pour la retirer.

📊 Générer le PowerPoint

Une diapositive de couverture, puis une diapositive par KPI, à la charte IDEA. Le complément Power BI y affiche le visuel connecté : le support se met à jour tout seul chez chaque lecteur qui a les droits. Pour qu'un visuel s'affiche, l'annuaire a besoin de son empreinte — ce que le complément mémorise lors d'une insertion. Un relevé par KPI, une seule fois.

Relever les empreintes manquantes — une seule fois par KPI
  1. 📋 Préparer le relevé télécharge un PowerPoint : une diapositive par KPI, avec son lien écrit en clair.
  2. Dans PowerPoint, pour chaque diapositive : sélectionnez le lien affiché, Insertion › Compléments › Power BI, collez-le, vérifiez que le graphique apparaît. Enregistrez.
  3. Revenez ici et déposez ce fichier sur cette fenêtre — ou 🔎 Relever les empreintes.

💡 Inutile de tout relever. L'annuaire apprend une différence sur deux relevés qui ne varient que par UNE chose, puis la rejoue partout. Faites donc, en ne changeant qu'un seul élément à la fois par rapport à un même relevé de référence :

  • la référence : un intitulé, une zone, une temporalité ;
  • + 1 relevé par autre temporalité (même intitulé, même zone) ;
  • + 1 relevé par autre zone (même intitulé, même temporalité) ;
  • + 1 relevé par autre intitulé (même zone, même temporalité).

Tout le reste s'en déduit. Une leçon ne vaut cependant que sur sa page de rapport : si vos KPI en couvrent plusieurs, refaites ce bloc sur chacune. Après chaque relevé, 📋 Préparer le relevé ne réclame plus que ce qui manque encore : ce compte est la vérité.

⚠ Collez toujours le lien affiché sur la diapositive. Repartager le visuel depuis Power BI crée un nouveau signet, et l'empreinte obtenue ne correspondrait à aucun KPI.

☁️ Synchronisation cloud

Synchronise automatiquement votre annuaire KPI et vos favoris entre tous vos appareils, via votre propre projet Firebase gratuit.

⚪ Synchronisation non configurée

⚠️ Vous avez ouvert l'application par double-clic sur le fichier (file://). Dans ce mode, la synchronisation cloud est impossible : Firebase refuse les connexions sans véritable adresse web. De plus, les données enregistrées ici sont séparées de celles de la version en ligne. Ouvrez l'application via son adresse https://… (GitHub Pages) pour que la synchronisation fonctionne.
Mon espace personnel
Inspecter un KPI

Tapez le début d'un intitulé pour voir, temporalité par temporalité, quels liens de site sont réellement enregistrés sur cet appareil.

✅ Configuration fournie par l'application — aucune saisie nécessaire. La synchronisation démarre automatiquement.
Historique des versions

Une copie est enregistrée automatiquement avant chaque réception de données du cloud. Vous pouvez revenir à un état antérieur.

Dépannage

En cas de données divergentes entre appareils, désignez celui qui a les BONNES données et écrasez le cloud avec, pour repartir sur une base saine.

Import / Export Excel

Exportez toutes vos fiches dans un fichier Excel (sauvegarde lisible et ré-importable), ou importez un fichier Excel pour créer / compléter vos fiches. Les liens de chaque site sont conservés comme liens cliquables.

⚙ Gérer les sites (périmètres)

Ajoutez, renommez ou supprimez les périmètres proposés dans les fiches KPI (par défaut : Logistiport, MG + Débords, Armateur, Global). Les modifications sont partagées et synchronisées.

🗑 Corbeille

Fiches supprimées de l'annuaire. Cochez celles que vous souhaitez réafficher.

🕓 Historique d'activité

Créations, modifications et suppressions de fiches, avec leur auteur et leur date. L'historique est partagé entre tous les appareils synchronisés.
